# WS UI/UX Demo

以合成案例體驗文件卡片、卷宗編排、紙本預覽及外觀切換，只供 UI/UX 回饋討論。

`index.html` 是自包含頁面，無需建置。GitHub Pages 可選擇主分支根目錄作為發布來源；`.nojekyll` 讓 HTML 直接發布。

此發布副本已將客戶、公司名稱與案號改為示例。沒有包含公司原始文件、工作區參考資料、既有留言或憑證。

## 回饋狀態

目前沿用共用資料夾回饋方式，尚未接上雲端留言服務。GitHub Pages 僅提供網頁，不會自動接收或儲存留言。要使用目前的共享回饋，需由使用者選取可存取的公司共用資料夾並授權；其他訪客只能保留本機紀錄或匯出。

後續預計保留目前的姓名必填表單，透過 Google Apps Script 將回饋存入 Google 試算表；此串接尚未完成。不要把 GitHub token 或其他私密 API key 放進 HTML。
